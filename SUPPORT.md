# Getting help

- **How do I...?** Start with the `README.md` and the documents in `docs/`.
  `docs/API.md` covers the library, the command line and the REST service.
- **Something is broken.** Open a bug report from the
  [Issues](https://github.com/SolidSeas/SolidSeas/issues) page.
  Please never attach confidential CAD files.
- **An idea or a missing feature.** Open a feature request from the same page.
- **A security problem.** Report it privately, as `SECURITY.md` explains.

SolidSeas is maintained by a small team in its spare hours, so answers can take
a few days. A clear report with steps to reproduce gets the quickest response.
