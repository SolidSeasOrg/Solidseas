2. SolidSeas Viewer (SolidSeasViewer.exe)
-----------------------------------------

The program is built by scripts/build-viewer.ps1 from packaging/SolidSeasViewer.spec, with the
exact packages and file hashes in requirements/build-windows.txt (64-bit Windows, CPython
3.12). It carries SolidSeas' own code and the components below. The build stops when it would
carry a Python package this file does not cover, or another version of one than this file
lists.

The program comes in two forms built from the same files: SolidSeasViewer.exe on its own (the
one-file build), and the one-folder build, a SolidSeasViewer folder holding SolidSeasViewer.exe
with its libraries and these licence texts as plain files in its _internal folder. The
installer, SolidSeas-Setup-<version>.exe, installs the one-folder build.

2.2 Qt, Qt for Python and the LGPL

SolidSeas uses Qt 6.12.0 and Qt for Python (PySide6 6.12.0 and shiboken6 6.12.0), as
published by The Qt Company in the PySide6-Essentials and shiboken6 wheels, under the GNU
Lesser General Public License version 3 (LGPL-3.0.txt), which adds permissions to the GNU
General Public License version 3 (GPL-3.0.txt). SolidSeas has not changed them. The wheels'
own licence files name only the Qt commercial licence; SolidSeas does not use Qt under that
licence, and the LGPL texts in the licenses folder are the ones that apply.

Source code. The exact source of the Qt and Qt for Python versions in the program:

  - Qt 6.12.0:
    https://download.qt.io/official_releases/qt/6.12/6.12.0/single/qt-everywhere-src-6.12.0.tar.xz
  - Qt for Python and shiboken6 6.12.0:
    https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.12.0-src/pyside-setup-everywhere-src-6.12.0.zip
  - The wheels the program was built from, checked by the SHA-256 hashes in
    requirements/build-windows.txt: https://pypi.org/project/PySide6-Essentials/6.12.0/ and
    https://pypi.org/project/shiboken6/6.12.0/

Copies of these two source archives are also attached to each SolidSeas release on GitHub
(https://github.com/SolidSeas/SolidSeas/releases), beside the program, for as long
as that release is offered.

If any of these stops being available, ask for the source by opening an issue at
https://github.com/SolidSeas/SolidSeas/issues and it will be provided at no charge
for as long as the release that carries it is offered.

Using another build of Qt. The LGPL lets you run SolidSeas with a modified version of Qt or
Qt for Python. How the program is built matters here:

  - The installer installs the one-folder build. Its Qt, PySide6 and shiboken6 libraries are
    plain DLL and PYD files in the _internal folder beside SolidSeasViewer.exe, at the paths
    BUNDLED-FILES.txt lists, and Windows loads them from there as shared libraries each time
    the program starts. To run SolidSeas with your own build of the same version, replace
    those files with yours. Nothing has to be rebuilt, which is the LGPL's shared-library
    option (section 4(d)(1)). The one-folder build also starts faster, and it is the
    recommended form. Installing over it, as a newer SolidSeas does, puts the original files
    back.
  - SolidSeasViewer.exe on its own is a PyInstaller one-file program. The Qt, PySide6 and shiboken6
    libraries are separate DLL and PYD files packed inside it (BUNDLED-FILES.txt names them),
    which Windows loads as shared libraries. Each time the program starts it unpacks them
    into a new folder named _MEI followed by digits in the Windows temporary folder, and it
    removes that folder when it ends. Replacing a file in that folder therefore lasts only
    until the program ends, and is not a practical way to use another Qt.
  - What does work: all of SolidSeas' source, the build script and the exact list of
    packages are published under the Apache License 2.0. To use your own Qt or Qt for
    Python, install your build of PySide6 and shiboken6 (same version, or a compatible one)
    into the build environment in place of the locked wheels, and run
    "scripts\build-viewer.ps1 -Venv <your environment> -SkipInstall". The program it builds
    is SolidSeas with your Qt. This is the relinking the LGPL asks for (section 4(d)(0)).
    SolidSeas' licence allows it, and allows the reverse engineering needed to debug such
    changes, as the LGPL requires.
  - From a source checkout (pip install solidseas[app]; python -m solidseas_app), PySide6 is
    an ordinary installed package and can be replaced directly.

The installer puts the program in the user's own folder (%LOCALAPPDATA%\Programs\SolidSeas)
unless an administrator chooses to install it for all users. Installed for all users, it is
in Program Files, where users cannot write, and that still meets the LGPL: an administrator
acting for the person or organisation that received the program can replace the files.

-------------------------

Each package is a zip built by scripts/build-extensions.ps1. Its manifest (extension.json)
carries its notices, shown on the Extensions page under Details.

5. Test files
-------------

tests/fixtures holds synthetic parts, assemblies and drawings made for this project through
the SOLIDWORKS API, and exports SOLIDWORKS wrote from them (tests/fixtures/README.md says how).
The assemblies and drawings were made from templates that the SOLIDWORKS installer ships.
tests/goldens holds files written by SolidSeas' own tests. Neither is part of the library
wheel, the program or the packages.
